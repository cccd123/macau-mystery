采用 Next.js 16 App Router 目录路由：`src/app/` 下按功能划分页面（`admin`、`community`、`create`、`game`、`login`、`my-scripts`），每个子目录通过 `page.tsx` 暴露路由，动态路由使用 `[sessionId]` 语法。
- 根布局 `layout.tsx` 统一注入字体（Geist Sans/Mono）、全局 CSS、`Providers`（i18n 上下文）、`Navbar`、`MouseFollower` 和页脚。
- UI 层由 `src/components/ui/` 下的 shadcn 原子组件（button、card、dialog、input 等）与业务组件（`script-editor`、`video-player`、`map-viewer`、`clue-card` 等）组成，通过 `@/components/*` 别名引用。
- 数据访问集中在 `src/lib/api.ts`，封装 `request<T>` 统一处理 Bearer Token、JSON 序列化与错误抛出；按领域拆分为 `gameApi`、`aiApi`、`ugcApi`、`adminApi`、`authApi` 五个命名空间对象。
- API 基地址由 `src/lib/api-base.ts` 的 `API_BASE` 环境变量控制，Next.js 构建时通过 `next.config.ts` 的 `rewrites` 将 `/api/v1/*` 代理到后端 `http://localhost:8000`。
- i18n 通过 `src/lib/i18n/context.tsx` 的 React Context + `useState` 实现，支持 zh-CN / zh-TW / en 三语，locale 持久化到 localStorage。
- 依赖方向：页面 → 业务组件 → UI 组件 → lib（api/i18n/utils），无反向依赖。
