- 所有客户端组件顶部显式标注 `"use client"`，服务端组件不标注，以区分渲染模式。
- API 调用统一通过 `src/lib/api.ts` 中各命名空间对象（gameApi/aiApi/ugcApi/adminApi/authApi）暴露的方法发起，禁止在页面中直接调用 fetch。
- 国际化文本一律通过 `useTranslation()` 返回的 `t(key)` 获取，key 为点号分隔字符串，回退到英文或原 key。
- UI 组件从 `@/components/ui/` 引入 shadcn 原子组件，业务组件从 `@/components/` 直接引入，路径均使用 `@/` 别名。
- 异步请求统一使用 `request<T>` 包装，错误通过 throw Error 上抛，页面侧用 try/catch 捕获并显示重试按钮。
- Token 通过 `localStorage.getItem('token')` 读取并自动附加到 `Authorization: Bearer <token>` 请求头。
