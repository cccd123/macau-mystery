- API 路由文件仅定义 FastAPI Router 与轻量处理器，业务逻辑全部委托给 `app/*_service.py` 中的类方法，保持路由薄、服务厚。
- 数据库访问统一通过 `app.db.get_db_session` 依赖注入 `AsyncSession`，并在需要事务的方法内使用 `session.begin()` 或显式 `commit()/rollback()` 包裹。
- 请求/响应模型集中在 `app/models.py`，继承自带 `extra='forbid'` 的 `GameContractModel`，并使用 Pydantic Field 的正则/长度约束进行入参校验。
- 业务异常通过 `app.game_errors.GameError` 抛出（携带 code/message/details），由 `main.py` 中的全局异常处理器统一序列化为 `{error:{...}}` 响应体。
- 配置项通过 `get_settings()` 单例获取，布尔值用 `_as_bool` 解析，整数用 `_positive_int` 校验，CORS 源用逗号分隔字符串转 tuple。
- 所有时间字段使用 `utc_now()` 生成带时区的 `datetime`，主键统一为 UUID v4（`new_uuid()`），状态字段通过 CheckConstraint 限制枚举值。
