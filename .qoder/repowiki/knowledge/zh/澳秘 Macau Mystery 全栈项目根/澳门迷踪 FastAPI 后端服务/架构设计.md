模块以 `app/main.py` 中的 `create_app()` 为应用工厂，通过 FastAPI lifespan 在启动时按需执行 demo 数据引导；所有业务路由按领域拆分为 `app/api/{game,auth,ai,admin,ugc,ugc_user}.py`，统一挂载到 `/api/v1/{domain}` 前缀。

- 配置层：`app/config.py` 使用 frozen dataclass + `@lru_cache` 暴露 `Settings`，从环境变量加载（`.env` / `.env.example`），区分 development/production 行为。
- 数据层：`app/db.py` 封装异步引擎（SQLite/PostgreSQL 双支持）与 `AsyncSession` 依赖注入；`app/db_models.py` 用 SQLAlchemy 2.0 Declarative 定义 Story/StoryVersion/GameSession/GameEvent/SessionClue/User/AuthSession 等模型，并通过 Alembic（`alembic/env.py` 支持 async migration）管理版本化迁移。
- 领域服务：`app/game_service.py` 实现游戏状态机与事务性选择处理（含 SQLite 的 `BEGIN IMMEDIATE` 并发保护、幂等 `request_id` 重放、clue 授予与结局判定）；`app/auth_service.py` 负责密码哈希（pwdlib）、Bearer Token 鉴权与演示账户引导。
- 故事引擎：`app/story/` 子包包含 JSON 脚本加载、图遍历（`engine.py`/`runtime.py`）、校验器（`validator.py`）与 CLI 导入工具。
- AI 能力：`app/ai/` 集成 OpenAI LLM、ChromaDB RAG、edge-tts 语音合成；`app/knowledge/` 维护澳门地标文档并入库 Chroma。
- UGC：`app/ugc/` 提供剧本自动生成与风格预设。

依赖方向严格单向：API → Service → DB Models，不反向依赖；异常统一通过 `app/game_errors.GameError` 抛出并由全局 handler 转为 `{error:{code,message,details}}` 结构。
