# Macau Mystery 项目 API 接口文档

- 文档状态：当前实现基线
- 版本：2.0
- 更新日期：2026-08-04
- 信息来源：`backend/app/main.py`、各 `backend/app/api/*.py` 路由和 Pydantic 模型

本文档取代原“游戏 API 契约”单一范围，记录当前已注册的全部项目接口。剧情 JSON 契约仍以 `02-story-data-contract.md` 为准；认证数据与安全边界见 `06-authentication-api-and-persistence.md`。

## 1. 通用约定

- 基础路径：`/api/v1`；交互式 OpenAPI：`/docs`；机器可读定义：`/openapi.json`。
- 请求与响应均为 JSON，除 `GET /ai/tts` 的 query 参数外；字段名使用 `snake_case`。
- 需要登录的接口使用 `Authorization: Bearer <token>`。登录、注册和游戏匿名接口不需要 token。
- 认证、游戏和健康检查使用数据库。AI、`create`、UGC 剧本、管理剧本和投稿的业务数据仍有 mock 或进程内存实现，服务重启会丢失。

### 错误格式

游戏业务错误与游戏请求校验错误统一为：

```json
{"error":{"code":"STALE_SCENE","message":"提交的场景不是当前游戏场景","details":{}}}
```

其他路由沿用 FastAPI 标准错误格式：

```json
{"detail":"Invalid credentials"}
```

字段校验失败时 `detail` 为错误数组，HTTP 状态码为 422。认证常用状态码为 401（凭据或 token 无效）、403（无管理员权限）、409（用户名重复）。

## 2. 接口总览

| 模块 | 方法与路径 | 鉴权 | 持久化状态 |
| --- | --- | --- | --- |
| 健康 | `GET /health` | 无 | 数据库连通性 |
| 游戏 | `POST /game/start`、`POST /game/choice`、`GET /game/state/{session_id}` | 无 | 已持久化 |
| 认证 | `POST /auth/register`、`POST /auth/login`、`GET /auth/me` | `/me` 需 Bearer | 已持久化 |
| AI | `POST /ai/chat`、`GET /ai/tts` | 无 | mock |
| 一句话短剧 | `POST /create/generate`、`POST /create/regenerate/{script_id}` | 无 | mock |
| 用户 UGC | `GET /ugc/my-scripts`、`POST /ugc/publish/{script_id}`、`POST /ugc/submit/{script_id}` | Bearer | 内存 |
| 管理后台 | `/admin/*` | 写入与投稿审核需管理员 | 内存 |

## 3. 健康检查

### `GET /health`

成功时返回：

```json
{"status":"ok","database":"ok","version":"0.2.0"}
```

数据库不可用时返回 503：`{"status":"degraded","database":"unavailable","version":"0.2.0"}`。

## 4. 沉浸式游戏 API（v1）

游戏会话匿名且绑定开局时的不可变剧情版本。后端只返回 `video` 或 `ending` 场景，绝不暴露内部 `router` 节点。

### 快照结构

三个游戏接口均返回下列快照；`awarded_clues` 只在选择成功响应中出现，`ending` 只在完成时出现。

```json
{
  "session_id": "UUID",
  "status": "active",
  "story": {"id": "macau_mystery_demo", "title": "澳门悬案演示", "version": 1},
  "scene": {
    "id": "scene_start",
    "type": "video",
    "chapter": {"id": "chapter_01", "title": "第一章：妈阁庙", "location": "妈阁庙"},
    "media": {"video_url": "https://...mp4", "poster_url": "https://...jpg", "mime_type": "video/mp4", "duration_ms": 10000},
    "choices": [{"id": "inspect", "text": "检查旧信", "preload": {"scene_id": "scene_letter", "media": {"video_url": "https://...mp4", "poster_url": "https://...jpg", "mime_type": "video/mp4"}}}]
  },
  "clues": [],
  "progress": {"current_chapter": 1, "total_chapters": 1}
}
```

每项 `preload` 都是模拟发放该选项线索并解析连续 router 后的权威候选媒体；前端仍必须调用 `/game/choice` 才能推进。

### `POST /game/start`

请求：`{"script_id":"macau_mystery_demo"}`。`script_id` 必须为 2–64 位小写字母、数字或下划线，且以字母开头。

成功返回 201 和活跃快照。失败可能为：404 `STORY_NOT_FOUND`、409 `STORY_NOT_PUBLISHED`、503 `STORY_NOT_READY`。

### `POST /game/choice`

请求：

```json
{"session_id":"UUID","scene_id":"scene_start","choice_id":"inspect","request_id":"UUID"}
```

成功返回 200 快照，附加本次新增的 `awarded_clues` 数组。相同 `session_id + request_id` 且内容相同会重放首次快照，不会重复推进；内容不同返回 409 `IDEMPOTENCY_CONFLICT`。

其他业务错误包括 404 `SESSION_NOT_FOUND`、409 `SESSION_COMPLETED`、`STALE_SCENE`、`CHOICE_NOT_AVAILABLE`，以及 500 `STORY_DATA_CORRUPTED`。

### `GET /game/state/{session_id}`

`session_id` 为 UUID。成功返回 200 当前快照（已完成会话返回结局场景和 `ending`）；会话不存在为 404 `SESSION_NOT_FOUND`。

## 5. 认证 API

用户名为 3–32 位、以英文字母开头、其余可用字母/数字/下划线；大小写不敏感唯一。密码为 6–128 位。注册和登录成功均返回：

```json
{"token":"随机 Bearer token","user":{"id":"UUID","username":"abcde","nickname":"user01","role":"user"}}
```

### `POST /auth/register`

请求：`{"username":"abcde","password":"123456","nickname":"user01"}`；`nickname` 可省略或为空，此时回退为用户名。

成功返回 200 并自动创建会话。重复用户名返回 409 `{"detail":"Username already exists"}`。

### `POST /auth/login`

请求：`{"username":"abcde","password":"123456"}`。用户名大小写不敏感。

成功返回 200 与上述 token/user 对象；用户不存在、密码错误或用户被停用均返回 401 `{"detail":"Invalid credentials"}`。

### `GET /auth/me`

请求头：`Authorization: Bearer <token>`。成功返回 200：`{"id":"UUID","username":"abcde","nickname":"user01","role":"user"}`；缺失、无效或过期令牌返回 401。

开发环境默认创建 `admin/admin123`（角色 `admin`）与 `guest/guest123`（角色 `user`）；生产默认关闭该行为。

## 6. AI 与一句话短剧（当前 mock）

### `POST /ai/chat`

请求：`{"npc_id":"mage_temple_keeper","message":"妈阁庙的历史？","context":{}}`，其中 `context` 可省略。

返回 200：`{"response":"...","audio_url":null}`。当前仅对内置 NPC ID 返回固定文案，未接入真实 LLM。

### `GET /ai/tts`

Query：`text`（必填）、`voice`（可选，默认 `zh-CN-XiaoxiaoNeural`）。返回：`{"audio_url":"","text":"..."}`。当前不生成音频。

### `POST /create/generate`

请求：`{"input":"故事描述","style":"suspense","options":{"era":"qing"}}`；`style` 默认 `suspense`，`options` 可省略。

返回 200：`{"script_id":"8位字符串","title":"AI生成短剧: ...","chapters":[...],"style":"suspense","era":"qing"}`。章节是固定 mock 数据。

### `POST /create/regenerate/{script_id}`

返回 200：`{"script_id":"路径参数","status":"regenerated"}`。当前不读取或写入真实剧本。

## 7. 用户 UGC API（Bearer，当前内存实现）

以下接口都需 Bearer token。`user_scripts_db` 目前没有与 `/create/generate` 的持久化连接，服务重启后内容丢失。

### `GET /ugc/my-scripts`

返回当前用户所属的内存剧本数组；无剧本时为 `[]`。

### `POST /ugc/publish/{script_id}`

请求：`{"is_public":true}`，默认 `false`。成功返回更新后的剧本对象；剧本不存在为 404，不属于当前用户为 403。

### `POST /ugc/submit/{script_id}`

请求可选：`{"message":"投稿说明"}`。剧本必须存在、属于当前用户且已公开；成功返回 `{"submission_id":"8位字符串","status":"pending"}`。未公开时返回 400。

## 8. 管理后台 API（部分内存实现）

除只读的 `GET /admin/scripts`、`GET /admin/stats` 与 `GET /admin/route` 外，其余写入/审核接口均需管理员 Bearer token。管理员认证失败返回 401，普通用户返回 403。

### 剧本管理

| 方法与路径 | 请求 | 成功响应 |
| --- | --- | --- |
| `GET /admin/scripts` | 无 | 内存剧本数组 |
| `POST /admin/scripts` | `{"title":"必填","description":""}` | 新建 draft 剧本对象 |
| `PUT /admin/scripts/{script_id}` | `{"title"?:"","description"?:"","status"?:""}` | 更新后的剧本；不存在为 404 |
| `DELETE /admin/scripts/{script_id}` | 无 | `{"message":"Deleted"}`；不存在为 404 |
| `POST /admin/scripts/{script_id}/publish` | 无 | `{"status":"published"}` 或 `{"status":"draft"}` |
| `POST /admin/scripts/ai-generate` | `{"input":"必填","mode":"quick"}` | 内存 draft 剧本；`mode` 可为 `quick` 或其他字符串 |

剧本对象包含 `id`、`title`、`description`、`status`、`chapters_count`、`players_count`、`views_count`、`created_at`、`route`；AI 生成对象额外含 `chapters`。

### 统计、投稿审核与路线

| 方法与路径 | 鉴权 | 成功响应 |
| --- | --- | --- |
| `GET /admin/stats` | 无 | `{"total_scripts":0,"total_players":0,"total_views":0,"published":0,"drafts":0}` |
| `GET /admin/submissions` | 管理员 | 内存投稿数组 |
| `POST /admin/submissions/{sub_id}/approve` | 管理员 | `{"status":"approved"}`；不存在为 404 |
| `POST /admin/submissions/{sub_id}/reject` | 管理员 | `{"status":"rejected"}`；不存在为 404 |
| `GET /admin/route` | 无 | 已发布剧本路线或默认六景点名称数组 |

## 9. 部署与联调说明

- 前端默认请求 `http://localhost:8000/api/v1`，可通过 `NEXT_PUBLIC_API_URL` 覆盖；当前登录页仍直接使用本地后端地址。
- CORS 来源由 `CORS_ORIGINS` 控制。生产必须设置正式前端域名，并关闭 `BOOTSTRAP_DEMO_STORY` 与 `BOOTSTRAP_DEMO_USERS`。
- 正式视频应由对象存储/CDN 直接提供，不经 FastAPI 转发。
- SQLite 部署必须绑定持久卷；不要在需要保留用户或游戏进度时执行 `docker compose down -v`。
